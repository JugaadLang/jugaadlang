Getting Started

JugaadLang is a Hindi-keyword programming language that transpiles directly to Python's AST, so it runs with zero runtime overhead and has full access to the Python ecosystem.

Your first program

Create a file named namaste.jug:

lao ganit banao namaste(naam): bolo("Namaste, " + naam + "!") bolo("Pi ki value hai: " + shabd(ganit.pi)) namaste("Duniya")

Run it:

jug run namaste.jug

How it works

Every JugaadLang keyword maps 1:1 to a Python keyword or builtin — agar is if, banao is def, bolo is print. Under the hood, the lexer and parser build a Python AST directly, so there's no separate interpreter to slow things down. See Syntax & Keywords for the full mapping.

New to the project? The Contributor Guide covers local dev setup, linting with ruff, and running tests with pytest.

Installation

Install via pip

pip install jugaadlang

This installs the jug CLI, the language runtime, and the standard library.

Verify the install

jug --version jug doctor

From source (for contributors)

git clone https://github.com/JugaadLang/jugaadlang.git cd jugaadlang pip install -e .[dev,all]

This installs JugaadLang in editable mode along with development and optional dependencies, as described in the CONTRIBUTING.md at the project root.

Standard Library

Standard library modules are imported with lao and use Hindi module names.

ganit — Mathematics

Hindi wrapper around Python's math module.

FunctionPython Equivalent
